# Three-minute demo

1. Open Today. Select **Start practice**, work on a problem, then **Finish & log practice**. Record an outcome and confidence. Show the saved problem in Practice and the activity in Progress.
2. Open **Your study plan**. Explain that availability and timezone determine study slots. **Move time** opens a confirmation form; no AI response changes commitments automatically.
3. With a configured account, select **Connect Fo** and complete Wajo consent. The connection belongs to the signed-in user.
4. In **Accountability preferences**, select **Preview demo missed session**. Read the visible **DEMO EVENT** instructions. Explain that the missed session is simulated but the message will be real. Obtain permission, check the confirmation box and select **Confirm and send**.
5. Show actual status and reply. If working, show progress and polling; if an error or uncertain delivery occurs, say so. Never present a mock response as Fo's reply. A question can be answered with **Reply to Fo**, followed by a separate preview and confirmation.
6. If authenticated discovery supports it, select **Talk to Fo → Create voice link → Open browser conversation**. This is microphone audio in the browser, not a telephone call.
7. Explain the current verification status honestly. Only demonstrate automatic check-ins after the deployed scheduler has passed the browser-closed test. Outbound phone reminders remain unavailable until ownership, consent and cancellation can be enforced.
